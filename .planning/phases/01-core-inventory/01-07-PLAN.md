Add a logout button to `src/components/layout/MobileNav.tsx` that calls the existing `logoutAction` server action.

**Current state:** MobileNav has 4 items (Cellar, Ready Now, Add+, Insights) with no logout. `logoutAction` exists in `src/app/login/actions.ts` but is never called from UI.

**Implementation:**

1. Import `logoutAction` from `@/app/login/actions.ts` at the top of MobileNav.tsx.

2. Import `LogOut` icon from `lucide-react` alongside the existing imports.

3. Add a `<form action={logoutAction}>` with a submit button styled as an icon button. Place it as a small logout icon in the top-right corner of the nav bar — NOT as a 5th tab (don't disrupt the 4-tab layout). Use `position: absolute` or wrap within a relative container.

   Specifically: wrap the `<nav>` content div in a `relative` div, and place the logout button absolutely at `top-2 right-2` (or similar) as a small ghost button with the LogOut icon (16×16 or 18×18) at low opacity (`text-white/30 hover:text-white/60`).

   **Why `<form action={logoutAction}>`:** `logoutAction` is a Server Action that calls `redirect()`. In Next.js 15, calling a Server Action that redirects from a Client Component requires submitting it via a form — calling it as a function directly from onClick would throw "redirect() called in a client context" because the redirect happens server-side.

   **Alternative if form approach has issues:** Import `logoutAction` and wrap the button in: `<button onClick={() => logoutAction()}>` — Next.js 15 client components can call Server Actions as async functions; the redirect will be handled by the router.

4. The logout button should have `aria-label="Logout"`.

5. Do NOT add a 5th tab to NAV_ITEMS. The 4-tab structure (Cellar, Ready Now, Add, Insights) must remain unchanged.
